# 题库示例

将题库文件放在此目录下，支持以下格式：

## Excel (.xlsx)

表头行必须包含以下列（名称灵活匹配）：

| 题型 | 题目 | A | B | C | D | 答案 | 解析 |
|------|------|---|---|---|---|------|------|
| single | 问题文本 | 选项A内容 | 选项B内容 | 选项C内容 | 选项D内容 | C | 解析文本 |

题型可选: single（单选）, multi（多选）, judge（判断）

## Markdown (.md)

每题用空行或 `---` 分隔：

```
1.下列情况不可以参加考试的是( )
A.张某：22周岁
B.李某：25周岁
C.王某：失信主体
D.赵某：18周岁
答案：C
解析：文化市场严重失信主体不得参加考试。

---

2.大型活动应提前多少天申请( )
A.5
B.10
C.15
D.20
答案：D
解析：需提前20日申请。
```

## JSON (.json)

直接使用标准格式：

```json
[
  {
    "type": "single",
    "q": "题目文本",
    "opts": ["A.选项1", "B.选项2", "C.选项3", "D.选项4"],
    "ans": "A",
    "explain": "解析文本"
  }
]
```

## Word (.docx)

段落格式同 Markdown，每段作为一行解析。
